# 0.1.0

- Original experimental BepInEx 5 plugin for On-Together on Windows.
- Background rendering cap; optional foreground cap respects vSync and lower limits.
- FrameCare detection yields all frame limiting to that mod.
- Opt-in URP render-scale, shadow-distance, and MSAA budgets.
- Settings restored only while still owned; external changes take precedence.
- Bounded frame-time metrics and local text/CSV reports with RAM and CPU counters.
- Explicit manual unused-asset cleanup, with confirmation and cooldown.
- No automatic sweeps, forced garbage collection, network patches, or game assets.
